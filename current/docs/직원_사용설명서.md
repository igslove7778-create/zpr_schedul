# 제피로스 일정관리 사용설명서

텔레그램으로 일정 등록과 오늘 일정 확인을 합니다. 직원은 구글시트를 사용하지 않습니다.

## 직원 사용법

### 일정 등록

텔레그램 봇에 아래처럼 보냅니다.

`9/15 오후 2시 팀 회의`

또는

`일정 2026-09-15 14:00 팀 회의`

시간을 쓰지 않으면 종일 일정으로 저장됩니다.

### 오늘 일정 확인

텔레그램에 `오늘`을 보냅니다.

내 일정과 나에게 공유된 일정이 나옵니다.

## 일정이 저장되는 곳

- 텔레그램 입력 → 일정 시트에 저장
- 팀 캘린더 반영 → 약 1분 안에 완료
- 텔레그램 답장 → 보통 3~4초

## 관리자 사용법

- 시트에서 일정 확인, 수정, 삭제
- 특정 사람에게 공유 → 그 사람 이름 칸에 `O` 표시
- 일정 삭제 → 행을 지우지 말고 상태를 `삭제`로 변경

## 알아둘 점

- 직원은 텔레그램만 사용
- 잘못 입력한 일정은 관리자에게 알림
- 관리자는 전체 일정 확인 가능
