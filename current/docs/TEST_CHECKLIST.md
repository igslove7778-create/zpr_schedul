# 회귀 테스트 체크리스트

수정 후 아래 순서로 확인.

- [ ] Apps Script 저장 성공
- [ ] 문법 오류 없음
- [ ] `zRunCalendarSyncNow` 수동 실행 성공
- [ ] 팀 캘린더 → 시트 신규 일정 반영
- [ ] 캘린더 위치 → 시트 장소 반영
- [ ] 설명 `김형원` → 대상자 1명
- [ ] 설명 `김형원, 김명재` → 대상자 2명
- [ ] 설명 `김형원, 김명재, 성도형` → 대상자 3명
- [ ] 설명 `김형원 김명재 성도형` → 대상자 3명
- [ ] 설명 `전체` / `전부` 정상
- [ ] 기존 `대상: 김형원, 김명재` 정상
- [ ] 일반 문장 `김명재 부장과 회의 후 자료 전달`은 대상자로 오인하지 않음
- [ ] 시트 수정 → 팀 캘린더 반영
- [ ] 대상자 변경 → 직원별 캘린더 복사본 갱신
- [ ] 같은 행에서 제목/시간/대상자를 3~4회 빠르게 연속 수정해도 다른 행 값이 바뀌지 않음
- [ ] 빠른 연속 수정 후 마지막으로 입력한 값이 팀/개인 캘린더에 남음
- [ ] 빠른 정상 수정 중 상태가 `삭제`로 바뀌지 않음
- [ ] 개인캘린더 신규 일정의 알람이 `대기`에 고정되지 않음
- [ ] 수신자 개인캘린더 복사본 삭제가 중앙 일정을 삭제하지 않음
- [ ] 실제 등록자 개인캘린더 일정 삭제는 시트 `삭제`로 정상 반영
- [ ] 시트 삭제 → 팀 캘린더 삭제
- [ ] 시트 삭제 → 직원별 복사본 삭제
- [ ] 삭제 일정이 다시 시트로 부활하지 않음
- [ ] 마지막 편집 후 약 1~2초 내 날짜별 정렬 완료
- [ ] Telegram 일정 조회/등록 기존 기능 정상
- [ ] 1분 동기화 트리거 정상
- [ ] 캘린더 변경감지 트리거 정상
