# 회귀 테스트 체크리스트

수정 후 아래 순서로 확인.

- [ ] Apps Script 저장 성공
- [ ] 문법 오류 없음
- [ ] `zRunCalendarSyncNow` 수동 실행 성공
- [ ] 팀 캘린더 → 시트 신규 일정 반영
- [ ] 캘린더 위치 → 시트 장소 반영
- [ ] 설명 `김형원` → 대상자 1명
- [ ] 설명 `김형원, 김명재` → 대상자 2명
- [ ] 설명 `김형원, 김명재, 성도형` → 대상자 3명
- [ ] 설명 `김형원 김명재 성도형` → 대상자 3명
- [ ] 설명 `전체` / `전부` 정상
- [ ] 기존 `대상: 김형원, 김명재` 정상
- [ ] 일반 문장 `김명재 부장과 회의 후 자료 전달`은 대상자로 오인하지 않음
- [ ] 시트 수정 → 팀 캘린더 반영
- [ ] 대상자 변경 → 직원별 캘린더 복사본 갱신
- [ ] 시트 삭제 → 팀 캘린더 삭제
- [ ] 시트 삭제 → 직원별 복사본 삭제
- [ ] 삭제 일정이 다시 시트로 부활하지 않음
- [ ] 날짜별 정렬 빠르게 완료
- [ ] Telegram 일정 조회/등록 기존 기능 정상
- [ ] 1분 동기화 트리거 정상
- [ ] 캘린더 변경감지 트리거 정상
