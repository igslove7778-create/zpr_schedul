# Changelog

## 2026-09-17

### Changed

- Google Calendar 설명란에 `대상:` 접두어 없이 구성원 이름만 입력해도 대상자로 인식
- 쉼표/공백 구분 모두 지원
- 1명, 2명, 3명 이상 지원
- `전체`, `전부` 지원
- 기존 `대상:` / `대상자:` 방식 하위 호환 유지
- 일반 문장이 섞이면 대상자 오인식하지 않도록 구성원 명단 전체 일치 검증

### Hotfix — 빠른 연속 수정 / 삭제 / 대기 상태

- 시트를 여러 칸 연속으로 빠르게 수정할 때 편집 중간에 행 정렬이 끼어들지 않도록 변경
- 마지막 편집이 끝난 뒤 약 1.2초 조용한 구간에서 날짜순 정렬을 한 번만 실행
- 여러 편집 트리거가 캘린더를 동시에 덮어쓰지 않도록 즉시 캘린더 반영을 직렬화하고, 반영 직전에 일정ID로 최신 행을 다시 읽음
- Google Calendar 증분 동기화의 `cancelled` 이벤트를 즉시 중앙 일정 삭제로 처리하지 않고, 같은 일정ID의 살아 있는 교체 이벤트가 있는지 먼저 확인
- 수신자용 개인캘린더 복사본 삭제는 중앙 일정 삭제로 전파하지 않음
- 개인캘린더에서 새로 들어온 일정이 `대기`에 머무르지 않도록 Telegram 즉시알림 결과를 `발송완료` / `실패` / `발송대상없음`으로 정리
- 기존 개인캘린더 일정 중 `대기` 상태도 다음 동기화 때 한 번 정리
