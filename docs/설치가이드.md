# 설치 가이드 (1단계 MVP)

관리자(담당자) Gmail 계정에서 진행합니다. 별도 서버 없이 구글 계정 안에서 운영됩니다.

## 1. 텔레그램 봇 만들기

1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 이름과 아이디(예: `zpr_schedule_bot`) 입력
2. 발급된 토큰(`123456:ABC-...`)을 복사해 둡니다. 토큰은 코드나 시트에 적지 않습니다.

## 2. 구글시트 + Apps Script 준비

1. 관리자 Gmail 로 새 구글시트를 만듭니다. 파일명 예: `제피로스 일정`
2. 메뉴 `확장 프로그램 > Apps Script` 를 엽니다.
3. `apps-script/` 폴더의 파일을 같은 이름으로 추가하고 내용을 붙여 넣습니다.
   - `Config.gs`, `Parser.gs`, `SheetRepo.gs`, `Auth.gs`, `Telegram.gs`, `Notify.gs`, `Setup.gs`
   - `appsscript.json` 은 `프로젝트 설정 > "appsscript.json" 매니페스트 파일 표시` 를 켠 뒤 내용을 교체합니다.
   - clasp 를 쓰는 경우: `clasp login` → `clasp create --type sheets --rootDir apps-script` 또는 기존 스크립트 ID 로 `.clasp.json` 작성 → `clasp push`
4. `프로젝트 설정 > 스크립트 속성` 에 추가:
   | 속성 | 값 |
   |---|---|
   | `BOT_TOKEN` | BotFather 토큰 |
5. 편집기에서 `setup` 함수를 선택해 실행합니다. 권한 승인 창이 뜨면 허용합니다.
   - [일정]·[구성원]·[로그]·[설정] 시트와 트리거(편집 감지, 10분 리마인드)가 생성됩니다.

## 3. 웹앱 배포와 웹훅 등록

1. `배포 > 새 배포 > 유형: 웹 앱`
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (텔레그램 서버가 호출해야 하므로 필수)
2. 배포 후 나오는 웹앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사해 스크립트 속성 `WEB_APP_URL` 에 저장합니다.
3. 시트로 돌아가 새로고침 → 메뉴 `일정관리 > 웹훅 등록` 실행
   - 비밀 키 `WEBHOOK_KEY` 가 자동 생성되어 URL 에 붙습니다. 키가 다른 요청은 거부됩니다.
4. `일정관리 > 웹훅 상태 확인` 에서 `url` 이 설정되고 `last_error_message` 가 없으면 정상입니다.

코드를 수정한 뒤에는 `배포 > 배포 관리 > 수정 > 새 버전` 으로 다시 배포해야 웹훅에 반영됩니다. URL 은 바뀌지 않습니다.

## 4. 구성원 등록과 텔레그램 연결

1. [구성원] 시트에 이름·구글 계정(개인 Gmail)·권한(관리자/일반)·사용여부(Y)를 입력합니다.
2. 메뉴 `일정관리 > 구성원 열 동기화` → [일정] 시트에 구성원 이름 열이 생깁니다.
3. 메뉴 `일정관리 > 인증코드 생성` → 텔레그램 미연결 구성원에게 6자리 코드가 발급됩니다.
4. 각 구성원에게 코드를 전달합니다. 구성원은 봇을 찾아 `/start` 를 누르고 코드를 입력하면 연결됩니다.
   - 봇은 사용자가 먼저 말을 걸어야 메시지를 보낼 수 있으므로 전원 연결이 필요합니다.
5. [일정] 시트를 전 구성원에게 **뷰어** 권한으로 공유합니다. 편집 권한은 담당자만 가집니다.
   - [구성원]·[설정]·[로그] 시트에는 이메일과 텔레그램 ID가 있으므로, 같은 파일을 공유할 경우 시트 보호와 숨김을 걸거나 별도 파일로 옮기는 것을 권장합니다.

## 5. 사용법

**텔레그램 등록**

```
일정 6/6 18:30 전체회의 @전부
일정 9월 15일 방산IR 제출 @김유선 @성도형
일정 내일 오후 2시 거래처 미팅
```

- 대상자를 지정하지 않으면 본인 일정으로 등록됩니다.
- `오늘 일정`, `이번주 일정` 을 보내면 본인이 열람 가능한 일정 목록을 회신합니다.

**시트 직접 등록 (담당자)**

- 날짜·시간·일정·메모를 입력하고 '전부' 또는 구성원 열에 `o` 를 찍으면 자동으로 일정ID가 부여되고 알림이 나갑니다.
- 날짜나 일정명이 비면 셀이 붉게 표시되고 알림이 나가지 않습니다.
- 발송완료된 일정의 날짜·시간·대상자를 바꾸면 변경 알림이 나갑니다.
- 삭제는 행을 지우지 말고 메뉴 `일정관리 > 선택 행 삭제 처리` 를 사용합니다. 취소 알림이 나가고 행은 취소선으로 남습니다.

**설정 ([설정] 시트)**

| 키 | 기본값 | 의미 |
|---|---|---|
| 즉시알림 | Y | 등록 즉시 대상자에게 알림 |
| 당일리마인드시각 | 08:00 | 당일 일정 리마인드 시각. 비우면 미발송 |
| 사전리마인드분 | 30 | 시간이 있는 일정의 N분 전 알림. 0이면 미발송 |
| 오후해석시작시 | 0 | 오전/오후 없는 시각 해석 (D-01). 예: 1 이면 1~11시를 오후로 |
| 담당자명 | (빈값) | 시트 직접 입력 건의 등록자 이름. 비우면 첫 관리자 |

## 6. 점검 항목

- 텔레그램에 `일정 내일 10:00 테스트` 를 보내 [일정] 시트에 행이 생기고 회신이 오는지 확인
- [로그] 시트에 등록·알림 이력이 남는지 확인
- 미등록 텔레그램 계정으로 보내면 거부 메시지가 오는지 확인
- 웹앱 URL 에 키 없이 접근하면 `forbidden` 이 오는지 확인

## 운영 한도 (무료 Gmail 기준)

- 트리거 총 실행시간 하루 90분, UrlFetch 하루 20,000회. 구성원 5명 규모에서는 충분합니다.
- 10분 간격 리마인드 트리거는 하루 144회 실행되며 실행당 수 초 이내입니다.
